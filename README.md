# Рубеж (Frontline Forts)

Соревновательная дуэль фортов для Яндекс Игр: колода карт-построек, постройки встают на клетки поля 7×10 и стреляют сами, рубеж ползёт к врагу, одинаковые карты накладываются в звёзды. В разработке.

TypeScript, Phaser 4, Vite; основа — шаблон StarterPackYG.

```
npm install
npm run dev
```

- Требования — [`docs/TZ.md`](docs/TZ.md), план с контрольными точками — [`docs/PLAN.md`](docs/PLAN.md), журнал — [`docs/PROGRESS.md`](docs/PROGRESS.md).
- Как вести проект через Claude Code — [`START.md`](START.md).
- `npm run verify` — единственный критерий «готово».
