# Релизный пакет

Результат — папка `release/`, с которой владелец заполняет черновик в консоли Яндекс Игр. Требования к каждому файлу — §9 `docs/TZ.md`.

## Порядок

1. **Предусловия.** `npm run verify` зелёный. Есть отчёт `/yg-audit` за сегодня без ❌ — если нет, запусти `/yg-audit` и исправь найденное.
2. **Версия.** Возьми версию из `package.json`. Если архив с этой версией уже лежит в `release/`, подними последнюю цифру версии.
3. **Архив.** `npm run build`, `npm run zip`, `npm run check:build`.
4. **Промоматериалы.** `npm run promo`:
   - скриншоты: компьютер 1920×1080 и телефон 1080×1920 (окно 360×640 с `deviceScaleFactor: 3`), по 4 штуки, три — в бою (бой в разгаре, наложение звезды со вспышкой, падение башни), один — открытие сундука с картами; бои играют боты через `window.__game`;
   - видео 16:9 по сценарию §9: запись Playwright → ffmpeg-static → MP4 H.264, не длиннее 28 секунд; по желанию то же 9:16;
   - иконка 512×512 и обложки 800×470 для ru и en — композиции из SVG игры (две крепости, катапульта, снаряд в полёте), название — как в черновике языка, без рамок и скруглённых углов, не скриншоты.
5. **Проверка файлов.** Скриптом выведи таблицу: файл, размер в пикселях, вес, длительность видео. Сверь с §9. Открой и посмотри каждую картинку и несколько кадров видео: нет обрезанного текста, артефактов и пустых кадров.
6. **Тексты.** Напиши `release/draft-ru.md` и `release/draft-en.md` с полями: название, описание для SEO, «Об игре», короткое описание, «Как играть», ключевые слова, теги, категории. Рядом с каждым полем — число символов, посчитанное скриптом. Проверь лимиты §9 и то, что тексты полей не повторяют друг друга. «Как играть» описывает правила (порох, карты, зона застройки и рубеж, наложение звёзд, башни и крепость, короны) и управление на телефоне (протянуть карту на клетку или коснуться карты и клетки) и на компьютере (то же мышью, 1–4 — выбор карты, Escape — отмена и пауза). Отдельной фразой: соперники — записи боёв других игроков и боты. Clash Royale и другие игры не упоминаются.
7. **CREDITS.md.** Все внешние ассеты (шрифт, музыка, если есть) — с источником и лицензией.
8. **UPLOAD.md.** Пошагово для владельца:
   - открыть черновик, загрузить архив;
   - платформы: компьютер, телефоны iOS и Android; ориентация — портретная; языки — ru, en; возрастной рейтинг — 0+; категории и теги — из draft-файлов;
   - отметить «Игра использует облачные сохранения»;
   - заполнить тексты и загрузить материалы для каждого языка;
   - реклама: стики-баннер на телефоне (внизу) и на компьютере, опция «Использовать API для показа sticky-баннера»; автоматический полноэкранный режим;
   - лидерборд `trophies` (числовой, по убыванию), если ещё не создан;
   - покупки: если `features.iap = true` — товары `gems_80`, `gems_500`, `gems_1200`, `starter_pack` и `no_ads` с теми же названиями, описаниями и картинками, что в игре; если `false` — в консоли не должно быть активных покупок;
   - почта для обратной связи;
   - комментарий для модератора (готовый текст: прогресс сохраняется локально и в облаке сразу после действий; соперники — записи боёв других игроков, загруженные через асинхронный мультиплеер SDK (`ysdk.multiplayer.sessions`), а если записей нет — игровые боты, это подписано в бою; бой длится около 3 минут и после перезагрузки не продолжается, это задумано; полноэкранная реклама — только после боя по кнопке «В меню», начиная с 3-го боя; при сворачивании вкладки бой встаёт на паузу; таймеры сундуков идут по серверному времени);
   - открыть черновик с `&debug-mode=16`, проверить индикатор `IT`, пройти обучение и 4 боя, проверить звук и паузу при сворачивании вкладки, рекламу после 3-го боя, баннер в меню и его отсутствие в бою; со второго аккаунта найти свою запись соперником;
   - отправить на модерацию.
9. **Итог владельцу.** Список файлов в `release/` и три следующих действия.
