# Стиль графики (ART-01, ART-02)

> Временная графика Этапа 0: плитка, крепость и башня. Финальный набор — Этапы 2 и 5 (ART-01…ART-04); перед массовым рисованием — 2 концепта экрана боя на выбор владельца.

Один стиль для всего: поля, меню, иконок, промо. **Подростковое и «крутое», не детское** (решение владельца, 2026-10-27): стилизованное суровое средневековье — тёмный камень, кованое железо, шипы, рваные знамёна, огонь и искры, угловатые силуэты вместо округлых, насыщенная, но не конфетная палитра (глубокие синий и красный, сталь, уголь, золото как акцент), без «милых» глаз, улыбок и пастели. Ориентир по настроению — стратегии для 14+ (как в жанре), а не книжка для малышей. Толстый контур остаётся, читаемость на телефоне важнее детализации; вид сверху под небольшим углом — постройка выше своей клетки (ART-01). Людей и крови нет: постройки рассыпаются на кирпичики. Ни одного «голого» геометрического примитива: у каждого объекта есть форма, объём (светлая и тёмная сторона), блик и тень.

## Правила рисования (общие)

- **SVG вручную**, без растровых вставок, без `<text>` (шрифтов при растеризации нет — надписи делает игра), без фильтров (`filter`, `feGaussianBlur`) — их плохо и медленно рисуют resvg и браузеры телефонов. Разрешены `linearGradient`, `radialGradient`, `clipPath`, `opacity`.
- **Свет сверху слева.** Тёмная сторона — справа снизу.
- **Объём в три слоя**: заливка → тень (тот же цвет на 15–25 % темнее, фигура по правому нижнему краю, без контура) → блик (белый 35–55 %, пятно сверху слева, без контура). Можно мягкий градиент сверху вниз вместо отдельной тени.
- **Контур** — `stroke-linejoin="round"`, `stroke-linecap="round"`, толщина `6` для спрайта 128×128 (на экране 2,5–3 px). Внутренние линии — `3–4`.
- **Тень на земле** — эллипс под объектом, тёмный цвет фона, непрозрачность `0.18`.
- Скругления везде.
- **Силуэт важнее цвета** (ACC-01): виды объектов различимы в оттенках серого.
- **Никакой радуги и радужных мотивов** — ни в графике, ни в названиях, ни в промо.
- **Без чужих брендов и персонажей.**

## Спрайты поля (`art/sprites/*.svg`)

- Плитка — `viewBox="0 0 128 128"`. Постройка — `viewBox="0 0 128 168"`: нижние 128 единиц — её клетка (центр клетки — `y = 104`), верхние 40 — то, что выступает над клеткой. Тень — эллипс у `y ≈ 154`.
- Поля 6 единиц: ничего не выходит за `6…122`.
- Если объекты растут по уровням — младший занимает ~55 % клетки, старший ~92 %, у старшего — золотой акцент. Размер в кадре мерится при сборке (`atlas-bounds.json`) — значки и подписи ставятся по видимой части.
- Цифры и надписи в спрайт не рисуются — их добавляет игра.
- Имя файла = имя кадра атласа: `a–z 0–9 -`.
- Эффекты: `fx-sparkle.svg`, `fx-ring.svg` (уже есть) — белые, окрашиваются тинтом.

## Иконки интерфейса (`art/ui/*.svg`)

- `viewBox="0 0 24 24"`. Монохромные — заливка `currentColor` (пауза, настройки, книга, кубок, замок, видео, волна, сумка). Цветные — монета, звезда, сердце — с контуром и бликом.
- Без `id` и градиентов: иконка встречается на странице несколько раз, а `id` конфликтуют.

## Промо (`scripts/promo-scenes.ts`)

- Иконка 512×512 — главный объект игры крупно на фоне, без текста.
- Обложка 800×470 и витрина 1560×520 — композиция из спрайтов + название игры шрифтом Nunito (на каждом языке своё).
- Титр в конце видео — фон обложки и название.

## Проверка

`npm run art` собирает атлас и контактные листы `test-results/art/*.png` (`npm run art -- --sheet` — только листы) — смотреть глазами на светлом и тёмном фоне; на телефоне (DPR 3) клетка ~150 px — мелкие детали тоньше 2 px пропадают.
